# Skills

Published, **redacted** copies of the agent skills I use day to day. They are the working versions,
not a cleaned-up rewrite — the process sections and the gotchas are what actually run.

Two things to know before you copy one:

- **Internal identifiers are placeholders.** Model names, cluster partitions, shared-filesystem
  roots and private repo names appear as `<base-model>`, `<preemptible-partition>`, `<shared-fs>`
  and so on. Anything that hard-codes a path or a partition — `harness-guard/assets/preflight.py`
  especially — will not run until you substitute your own.
- **A few skills are omitted** because their content is mostly the shape of an internal pipeline,
  and redacting them would leave nothing readable behind.

Six of them form a closed loop, worth reading in this order:

| Skill | Role |
|---|---|
| [`cost-governor`](cost-governor/SKILL.md) | price a measured pilot, then gate the scale on a hard ceiling |
| [`harness-guard`](harness-guard/SKILL.md) | executable pre-flight before a job is submitted |
| [`exp-loop`](exp-loop/SKILL.md) | hypothesis with a predicted number → run → measure from raw logs → score |
| [`fleet-governor`](fleet-governor/SKILL.md) | watch what is alive; separate transient failure from deterministic |
| [`lesson-loop`](lesson-loop/SKILL.md) | capture a lesson, route it to the one place that changes behavior, verify it fires |
| [`skill-forge`](skill-forge/SKILL.md) | audit a skill against how it actually got used, and patch it |

The loop closes through what gets *mechanized*. A lesson that a check could catch becomes a
`harness-guard` check; one specific to a workflow becomes a line in that skill's gotchas via
`skill-forge`. So the checks that run before every job are grown from the failures of previous
jobs, and the set of things that can go wrong silently shrinks over time.

A worked example, from the run that produced `fleet-governor`: three training arms spent 224
resubmissions on a module name that was never created. Each attempt died in about two seconds, and
the retry loop — correctly built to survive preemption — could not tell that this failure was
deterministic. The measurement became a ledger entry, the cause became a pre-flight check that
resolves module references before submission, and the missing distinction became a skill.
